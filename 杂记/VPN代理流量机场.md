# 代理、VPN、流量、机场与 Clash 详解

这些概念经常一起出现（尤其是在科学上网、网络加速、开发调试场景中），但它们其实属于不同层次。本文按照 **流量 → 代理 → VPN → 机场 → Clash** 的顺序，从基础概念到实际使用，逐层梳理。

---

## 1. 流量（Traffic / Data）

### 1.1 什么是流量？

**流量就是网络中传输的数据量。** 你访问网页、看视频、下载文件，本质都是你的设备与服务器之间交换数据，这些数据的大小就是流量。

单位：B（Byte）→ KB → MB → GB → TB

| 操作 | 大约消耗流量 |
| --- | --- |
| 发文字消息 | 几 KB |
| 浏览网页 | 几 MB |
| 听音乐 | 50~100 MB/小时 |
| 看 1080P 视频 | 1~3 GB/小时 |
| 下载游戏 | 几十 GB |

### 1.2 上行与下行

- **下行流量**：从服务器下载到本地的数据（如看视频、下载文件）
- **上行流量**：从本地上传到服务器的数据（如发评论、传文件）

运营商统计的就是这些数据量的总和。

## 2. 代理（Proxy）

### 2.1 核心原理

代理的核心是：**代理服务器帮你转发网络请求。**

- 普通访问：你的电脑 → 目标网站
- 使用代理：你的电脑 → 代理服务器 → 目标网站

目标网站看到的是**代理服务器的 IP**，而不是你的真实 IP。

### 2.2 现实类比

> 你说："帮我买杯咖啡"
> 代理说："好的，我去买"
> 咖啡店看到的是代理，不知道真正的买家是谁。

### 2.3 代理的用途

1. **隐藏真实 IP**：网站看到的是代理 IP 而非你的真实位置
2. **访问限制内容**：通过特定地区的代理访问该地区限制的内容
3. **企业网络管理**：公司通过代理过滤网站、记录访问、安全审计

---

## 3. VPN（Virtual Private Network）

### 3.1 核心定义

VPN（虚拟专用网络）的本质是在公共网络上为你建立一条**加密的专属隧道**。

- **通俗比喻**：没有 VPN 时，你像穿着便服走在大马路上，谁都能看到你去哪，路边的黑客能偷听你的谈话；有了 VPN，你走进了一条全封闭的传送管道，数据全程加密，外人看不懂，也查不到你的真实位置。

### 3.2 三大核心作用

1. **加密隐私**：保护个人数据，尤其在连接公共 Wi-Fi 时防止被窃取
2. **隐藏 IP 地址**：网站看到的是 VPN 服务器的位置，而非你的真实地理位置
3. **突破地理限制**：通过切换服务器位置访问不同地区的网络资源

### 3.3 VPN 与代理的区别

| 维度 | 代理 | VPN |
| --- | --- | --- |
| 作用范围 | 单个应用 | 整个设备网络 |
| 是否加密 | 通常不一定 | 通常加密 |
| 速度 | 较快 | 可能慢 |
| 复杂度 | 简单 | 复杂 |
| 典型用途 | 访问某网站 | 保护全部流量 |

例如：浏览器设置代理后，只有浏览器走代理，微信等其它应用仍走正常网络；而 VPN 会接管整个设备的所有流量。

## 4. 机场

### 4.1 机场不是机场

这里的"机场"是指：**提供代理节点订阅服务的平台。** 通常提供 SS（Shadowsocks）、SSR、V2Ray、Trojan、Hysteria、Sing-box 等节点。

结构：你 → 客户端（Clash / Shadowrocket / sing-box）→ 机场节点 → 互联网

### 4.2 为什么叫机场？

网络社区里的比喻：节点 = 飞机，服务器集合 = 机场。购买"机场会员"就是购买使用这些线路节点的权限。

### 4.3 机场卖什么？

主要卖**流量套餐**，例如：月付 20 元，100GB 流量，包含日本、美国、香港、新加坡等节点。

### 4.4 机场与商业 VPN 的区别

| 维度 | 机场 | 商业 VPN |
| --- | --- | --- |
| 技术 | 代理节点 | VPN 协议 |
| 用户 | 技术用户多 | 普通用户多 |
| 配置 | 需要客户端 | 通常一键连接 |
| 协议 | 多种代理协议 | VPN 协议 |
| 控制 | 用户选择节点 | 软件自动 |

## 5. Clash

### 5.1 Clash 是什么？

Clash 是一款**代理客户端**，负责读取机场订阅、解析节点列表、选择节点并转发流量。

流程：机场订阅 → 客户端解析 → 选择节点 → 转发流量

### 5.2 Clash 的版本与下载

Clash **既有电脑版也有手机版**，但不同平台的版本和获取方式差异很大：

- **电脑端（Windows/macOS/Linux）**：有成熟的官方客户端（如 Clash Verge、CFW 等），下载配置相对直接。
- **安卓端（Android）**：有直接名为 Clash 的客户端（如 Clash Meta for Android、FlClash）。**注意**：国内应用商店通常没有，需要去 GitHub 下载 APK 安装包。
- **苹果端（iOS）**：**没有**直接叫"Clash"的官方应用。必须使用功能同源的替代品，如 **Stash**（完美适配 Clash 配置）、Shadowrocket（小火箭）或 Quantumult X（圈 X）。这些都需要用**非中国区 Apple ID** 才能在外区商店下载。

### 5.3 Clash 收费吗？流量从哪来？

**软件免费，但"道路"收费。**

- **软件本身**：Clash 客户端是**免费**的开源软件，下载安装不花一分钱。
- **节点/流量**：Clash 只是一个"播放器"，里面没有内置内容。你必须去第三方服务商（俗称"机场"）**付费购买订阅链接**，把链接填进 Clash 里，才能获得上网流量和代理线路。
- **结论**：如果只下载 Clash 而不买"机场"节点，软件处于空壳状态，**完全跑不动**。

### 5.4 Clash 和 VPN 的根本区别

既然 Clash 打开手机会显示 VPN 图标，那它到底算不算 VPN？**技术上不算，但形式上借用了 VPN 的接口。**

| 对比维度 | 传统 VPN（如 ExpressVPN） | Clash（代理工具） |
| --- | --- | --- |
| 工作模式 | **全局隧道**：所有流量全部强行绕道远端服务器 | **智能分流**：内置规则引擎，自动识别流量（国内直连，国外走代理） |
| 系统表现 | 直接接管系统网络层 | 借用手机系统的 **VPN 接口**来抓取流量（状态栏会显示 VPN 图标），但内核走的是 SOCKS5/HTTP 代理协议 |
| 效率影响 | 国内访问变慢（绕路） | 国内访问不受影响（直连），只有特定流量才走隧道，效率更高 |

## 6. 概念关系总览

```
                 网络访问
                    |
             你的电脑/手机
                    |
        -------------------------
        |                       |
      VPN                    代理
        |                       |
   VPN 服务器             代理服务器
        |                       |
        --------互联网---------
                    |
                  网站
```

机场提供代理服务器，卖节点和流量给 Clash 使用。

---

## 7. 开发者视角

对于程序员而言：

- **代理**：常用于 GitHub 访问、npm/pip 下载、Docker 拉镜像、API 请求
- **VPN**：常用于公司内网访问、云服务器安全连接、远程办公
- **机场**：更多是个人代理服务、网络出口切换

---

## 8. 一句话总结

| 名词 | 一句话理解 |
| --- | --- |
| 流量 | 网络传输的数据量 |
| 代理 | 别人帮你转发网络请求 |
| VPN | 建立加密网络隧道 |
| 机场 | 出售代理节点和流量的平台 |
| Clash | 管理代理节点的软件 |

最简单的比喻：

> **流量 = 水**
> **代理 = 帮你送水的人**
> **VPN = 加密的水管**
> **机场 = 提供很多水管入口的公司**

**Clash 是一款免费、需要外部购买节点流量、且利用"智能分流"技术（借用了 VPN 的系统接口）的代理客户端；而传统 VPN 是一条"不分青红皂白"把所有流量都装进去的加密全局隧道。** 如果已经买了"机场"节点，把订阅链接填进 Clash 并开启"规则模式"，它就能发挥比传统 VPN 更灵活、更高效的作用。
